## First-Time Setup

### Prerequisites
- Android Studio (download from https://developer.android.com/studio)
- Android SDK (installed via Android Studio)
- A physical Android device (API 29 / Android 10+) OR an emulator

### Install deps
```bash
cd android
npm install
```

### Open in Android Studio
```bash
npx cap open android
```
This opens the `android/android/` Gradle project in Android Studio.

### Register Plugins in MainActivity
In `android/app/src/main/java/com/ghostwolf/android/MainActivity.java`, add:
```java
import com.ghostwolf.plugins.privacy.GhostWolfPrivacyPlugin;
import com.ghostwolf.plugins.audio.GhostWolfAudioPlugin;

public class MainActivity extends BridgeActivity {
    @Override
    public void onCreate(Bundle savedInstanceState) {
        registerPlugin(GhostWolfPrivacyPlugin.class);
        registerPlugin(GhostWolfAudioPlugin.class);
        super.onCreate(savedInstanceState);
    }
}
```

### Add permissions to AndroidManifest.xml
```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PROJECTION" />
```

### Build & Run
In Android Studio: Run → Run 'app' (or Shift+F10)

## How It Works

### Privacy (FLAG_SECURE)
`GhostWolfPrivacyPlugin` sets `FLAG_SECURE` on the Android Activity window. This is applied immediately on app startup via `deviceready`. Any screen share (Zoom, Meet, Teams) will see a **black rectangle** where GhostWolf is.

### STT — Groq Whisper (default)
Records 3-second audio chunks from the microphone, sends them to `api.groq.com/openai/v1/audio/transcriptions` using `whisper-large-v3-turbo`. Requires a Groq API key (free at console.groq.com).

### System Audio (Android 10+)
`GhostWolfAudioPlugin` triggers the `MediaProjection` permission dialog. Once granted, it captures system audio (what others say in a meeting). Combined with the mic channel, GhostWolf hears both sides.

### LLM
`llm-mobile.js` streams responses from Groq/Gemini/OpenAI using the standard `/chat/completions` SSE endpoint. Auto-falls back to the next configured provider on quota/connection errors.

### Auto-Assist
When the STT engine detects the "them" channel speaking, GhostWolf automatically queues a `say` mode prompt 800ms later — just like the desktop version.
